# LAKSHYA 07 Computer Institute — Frontend

Frontend-first implementation for the LAKSHYA 07 Computer Institute website.

## Stack
- React + TypeScript + Vite
- React Router
- Tailwind CSS and responsive custom CSS
- Lucide icons

## Run locally
```bash
npm install
npm run dev
```

## Current scope
- Public website pages and course catalogue
- Individual course details
- Admission enquiry UI with WhatsApp handoff
- Initial English/Hindi language toggle
- Student portal demo screens
- Admin dashboard demo screens
- Mock course, enquiry and student data

## Important
This is a frontend prototype. Forms, dashboard changes, student login and result data are not persisted and are not secure authentication. Do not enter real student information. Supabase, backend APIs, authentication and RLS will be implemented in a later phase.

The current logo is a temporary text-based mark because the existing institute logo file has not yet been added to this repository. Replace it with the approved logo asset when supplied.

Institute claims, affiliation, review count, timings, syllabus and certificate details should be verified before public launch.
